## 🎵 AuroraMusic v0.3.0 发布

首款 Aurora 风格的 **本地音乐播放器 + 游戏内音乐/麦克风混音输出工具**。

### ✨ 主要功能
- 🎼 支持 MP3 / FLAC / WAV / APE / M4A / OGG 等主流格式本地音乐播放
- 🎮 游戏混音输出：**音乐 + 麦克风** 混合后输入到 VB-CABLE，队友同时听到歌与说话声
- 🎙️ 独立监听控制：本地监听音量与队友听到的音量独立控制
- ⚡ 全局快捷键：播放/暂停/切歌/混音开关（Ctrl+Alt+M）
- 🗒️ 播放列表 / 收藏：本地歌单管理（SQLite）
- 🌙 暗黑 Aurora 风格界面

### 🛠️ 已修复 Bug
- ✅ 修复 BASS 引擎调用失败导致混音失效（替换 ffi-napi 为 koffi）
- ✅ 修复混音开关点击后错误弹出安装窗口
- ✅ 修复麦克风通道未加入混音器（队友只能听到音乐）
- ✅ 修复音量调控滑块无效
- ✅ 修复 BASS 设备名称中文乱码
- ✅ 修复 BASS_StreamPlay 废弃函数问题
- ✅ README 图片国内 CDN 加速显示

### 🚀 使用前准备
1. 安装 **VB-CABLE 虚拟驱动**（混音功能必需）
2. 游戏设置 → 麦克风选择：`CABLE Output (VB-Audio Virtual Cable)`
3. 游戏设置 → 扬声器保持默认耳机/扬声器（**不要改到 CABLE Input**）

详见 README：https://github.com/JinIilaiQiaoMen/AuroraMusic/blob/main/README.md
